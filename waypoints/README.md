# Waypoints

Queue a route instead of clicking one step at a time. Alt-click the ground as many times as you like and
the character walks the points in order, with a flag standing on each one still to come.

## Usage

1. **Alt-click** the ground where you want to go. The character sets off, and a flag marks the spot.
2. **Alt-click again** to add the next point. Each one joins the end of the queue and gets a flag of its
   own.
3. **Click the ground normally** to drop the whole queue and walk there instead, the way you always do.

The leg being walked is drawn in green and the ones still queued in yellow. A flag comes down as the
character reaches it.

## Notes

- Every character keeps a route of its own. The one you are looking through is drawn bright, and the
  others faded, so you can see where the rest are headed.
- Alt-clicking an object is left to the game, so only the bare ground queues a point.
- A right-click never replaces the route.
- A route the character cannot go on with — the way is blocked, or the server refused the walk — is
  dropped after a second of standing still, rather than leaving flags on the map.
